# 青学笃行｜青年学习 H5

中国银行益阳分行青年理论学习主题栏目。页面包含栏目导语、理论研学/团课学习/政策解读/学习感悟四个版块，以及 19 位青年的照片、自我介绍与学习感悟展示位。

## 员工素材补录

人物数据集中在 `app/page.tsx` 顶部的 `youthProfiles` 数组。素材到位后：

1. 将照片放入 `public/people/`。
2. 按顺序补充姓名、机构、岗位、照片路径、自我介绍和学习感悟。
3. 如需调整照片构图，修改对应人物的 `imagePosition`。

## 本地运行

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
```
